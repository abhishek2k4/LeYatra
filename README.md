# LeYatra

A real-time bike ride-hailing platform.

## Architecture

- Passenger Android application
- Driver Android application
- Admin web portal
- Node.js backend
- MongoDB database
- Socket.IO realtime communication

## Development

### Install dependencies

npm install

### Start MongoDB

docker compose up -d

### Start backend

npm run dev:server

### Run type checking

npm run typecheck

### Build backend

npm run build:server
